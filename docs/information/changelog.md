# What's New

Release notes for provide-foundation are published on GitHub, attached to the
release they describe.

**[Browse all releases →](https://github.com/provide-io/provide-foundation/releases)**

Each release page carries the notes for that version alongside the artifacts it
shipped: the wheel and sdist, their Sigstore signatures, and a CycloneDX SBOM of
the wheel's dependency closure.

Packages are on [PyPI](https://pypi.org/project/provide-foundation/).

This page deliberately holds no copy of the notes. It used to, and the copy
stopped at 0.1.0-beta.2 while the project went on releasing — a changelog that
looks maintained and is not is worse than no changelog at all. One source of
truth, and it is the one the release automation already writes to.
